# imagenes-impresion-3d

Repositorio para assets e imágenes destinadas a **impresión 3D** (referencia / trabajo local).

## Estado

Carpeta local y remoto GitHub inicializados. Añade aquí los archivos de diseño o renders que quieras versionar.

## Uso sugerido

```
imagenes-impresion-3d/
├── README.md
├── .gitignore
├── raw/          # fuentes (opcional, local)
├── exports/      # STL / OBJ / renders listos
└── docs/         # notas de impresión
```

No mezclar con `automation-scripts/automation-utilities` (utilidades imagen→STL) ni con firmware/navegación.
